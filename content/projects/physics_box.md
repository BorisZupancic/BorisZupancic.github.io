This is a sandbox-style game running a simple 2D physics engine. The player can generate balls of varying radius inside the sandbox, play with some dials controlling gravity, particle collision, time etc, and watch what happens. 

I started it to try and teach myself the C programming language, using the game engine [raylib](https://www.raylib.com/). It remains incomplete (there are some bugs, and there is more physics to add).

If you want to try *PhysicsBox* yourself, or view the source code, you can visit my [GitHub](https://github.com/BorisZupancic/PhysicsBox).
